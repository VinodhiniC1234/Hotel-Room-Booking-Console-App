# 🏨 Hotel Room Booking Console App

A Java Console-based Hotel Room Booking System developed using **Core Java**, **Object-Oriented Programming (OOP)**, **Collections**, **File Handling**, and **Java Date API**. The application simulates a real-world hotel booking system where users can search rooms, book rooms, manage guest information, calculate bills, cancel bookings, and maintain booking history.

---

# 📌 Project Overview

The **Hotel Room Booking Console App** is a menu-driven Java application that allows users to perform hotel booking operations through the command line. It demonstrates the implementation of real-world business logic using Java programming concepts.

---

# 🎯 Problem Statement

Managing hotel room bookings manually can lead to booking conflicts, incorrect billing, and inefficient record management.

This project automates the booking process by allowing users to:

- View available rooms
- Search rooms by type
- Book rooms
- Store guest information
- Generate booking IDs
- Calculate bills
- Cancel bookings
- Maintain booking history
